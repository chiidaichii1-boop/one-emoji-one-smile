Entry for the [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) bounty on make.fun.

`main.py` writes exactly one emoji — a sunflower 🌻 — to `/output/entry.txt`:
warm at first glance, universal, and picked for the moment rather than
the default smiley. A small sunny gift from a stranger, with no irony,
intimacy, or in-joke that could land wrong.
